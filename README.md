This submission analyses two raw NMEA 0183 GPS recordings. It validates NMEA checksums, decodes valid GPS fixes, identifies the stationary and moving recordings, estimates horizontal position repeatability and summarizes other available satellite/quality data.

## 1. Requirements

- Python 3.10 or later
- NumPy and Matplotlib (specified in `requirements.txt`)

## 2. How to run

Open a terminal **in this folder**, then install the dependencies:

```bash
python3 -m pip install -r requirements.txt
```

Run the analysis:

```bash
python3 GPS_analysis.py nmea-test1-1.txt nmea-test2-1.txt --out-dir GPS_results
```

On Windows, use `python` instead of `python3` if that is the command configured on your machine.

The script prints data checks and computed statistics to the terminal. To save that text for your own review, run:

```bash
python3 GPS_analysis.py nmea-test1-1.txt nmea-test2-1.txt --out-dir GPS_results > GPS_results_stats.txt
```

The analysis is non-interactive; it saves figures directly to PNG files (you do not need to open a graph window).

## 5. Interpretation cautions

- **Test 1 is stationary; Test 2 is moving.** GPS drift causes non-zero apparent movement in stationary recordings.
- Empirical **R95** is the radius containing 95% of measured points around the sample mean, not a measured absolute accuracy/error bound.
- Absolute GPS accuracy cannot be measured without a known reference coordinate.
- The recorded track length is the sum of successive GPS-point distances, not a surveyed walking distance.
